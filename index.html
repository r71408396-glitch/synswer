Synswer

Ask Anything. Understand Everything.

Synswer reads trusted public sources, cross-checks them and explains the result in plain language, with the sources one tap away. Type a question, attach a photo or file, or speak it.

What Synswer can do

Sourced answers

Combines Wikipedia, instant answers, Hacker News, Stack Overflow and scholarly papers, and lists the sources it used.

Live web research

Time-sensitive questions such as news and prices trigger a live web search with links you can open.

Images and files

Attach a photo, an image or a text, CSV, Markdown or JSON file and ask about it.

Voice input

Press Speak to dictate your question, where your browser supports it.

Code, tables, lists

Answers can include headings, bullet points, tables and code blocks. Download an answer, or its table as CSV.

Optional memory

Signed-in members can let Synswer remember context, and clear it any time from an answer.

How it works

  1. 1

    Ask

    Type, speak or attach something.

  2. 2

    Check

    Synswer gathers and filters public sources for relevance.

  3. 3

    Explain

    You get a clear answer with the sources listed. Check important facts.

    Sources checked

      Synswer checks several public sources for each question (Wikipedia, DuckDuckGo instant answers, a live web search for time-sensitive questions, Hacker News, Stack Overflow and scholarly papers), filters them for relevance, cross-checks them and explains the result in its own words. It is not a full Google-style web search, and headlines and titles are not full articles. Check important facts.
